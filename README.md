# Quill

> [!Note]
> Very much work in progress. I don't even have any proper docs for this yet. Just the inspiration.

A markdown editor that ouputs PDFs styled like you might find in the Dungeons & Dragons core rulebooks.

Heavily inspired by Naturalcrit's [Homebrewery](https://homebrewery.naturalcrit.com/). Go check it out if you want something that works right now. The difference between that and this, is that this is local and offline first, while Homebrewery is browser based.

## Running the Application

```bash
$ pnpm install
$ pnpm start
```
